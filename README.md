## 🧩 Featured Projects

### 🛍️ Karyakshetram: AI-Powered Retail Expansion Platform
Ranks candidate store locations by predicted revenue and profit, with P10/P90 uncertainty bands and viability tiers.
- Hybrid **Huff gravity model + LightGBM**, validated on spatially held-out cells against a population-only baseline
- Portfolio planner that selects stores by marginal network profit after cannibalization
- **SHAP explanations** with a validator that rejects any narrative number not found in the evidence record
- MERN + FastAPI, deployed with Docker on Render and MongoDB Atlas

`React` `Node.js` `Express` `MongoDB Atlas` `FastAPI` `LightGBM` `SHAP` `RAG` `Docker`

### 📈 Atlas: AI-Powered Portfolio Risk Intelligence Platform
Portfolio analytics with a risk engine and a natural-language assistant.
- Python engine for volatility, Sharpe ratio, maximum drawdown, **VaR** and asset correlation from historical market data
- **RAG assistant** that answers portfolio questions using the platform's calculated metrics as context
- Dashboards for returns, allocation, risk exposure and stress-test scenarios

`React` `TypeScript` `FastAPI` `PostgreSQL` `RAG`

### ⚙️ Smart Workflow Automation and Task Management System
Task management with automated workflows and real-time collaboration.
- Real-time notifications over **Socket.IO** for assignments, status changes and approaching deadlines
- **Redis + BullMQ** queues for background jobs and workflow triggers
- Role-based access control and dashboards for workload and deadline progress; containerized with Docker

`React` `TypeScript` `Node.js` `Express` `PostgreSQL` `Redis` `BullMQ` `Socket.IO` `Docker`
